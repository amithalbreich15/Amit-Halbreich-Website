## 📦 Installation & Development

```bash
# Clone the repository
git clone https://github.com/amithalbreich15/Amit-Halbreich-Website.git

# Navigate into the project folder
cd Amit-Halbreich-Website

# Install dependencies
npm install

# Start local development server
npm run dev
```

> The site will be available at `http://localhost:5173` (if using Vite)

---

## 🔧 Build & Deploy

To build the app for production:

```bash
npm run build
```

To deploy on GitHub Pages:

1. Make sure the `homepage` field is correctly set in `package.json`
2. Use:

```bash
npm run deploy
```
